## Summary

App Identity wires the Sprint app's visual identity end-to-end: bilingual ARB localisation (Arabic default, English secondary), a Riverpod `ThemeMode` provider (dark default, light secondary), a Riverpod `Locale` provider, a pixel-perfect Flutter splash screen matching the Claude Design prototype, a login screen placeholder for post-splash navigation, native OS splash backgrounds, and app-icon assets. All switching is driven by Riverpod providers — no app restart required.

---

## Technical Context

**Language/Version**: Dart 3.11.1 · Flutter SDK (≥3.11)

**Primary Dependencies** (all already in `pubspec.yaml`):
- `flutter_riverpod ^2.6.1` + `riverpod_annotation ^2.4.1` — state management
- `go_router ^14.3.0` — navigation
- `intl ^0.20.2` + `flutter_localizations` — l10n
- `riverpod_generator ^2.4.4` + `build_runner` — code generation

**Storage**: None — theme + locale persistence deferred to the Settings feature (see `research.md`).

**Testing**: `flutter_test` · `mockito`/`mocktail` for Riverpod provider unit tests.

**Target Platform**: iOS 15+ · Android API 21+ · Flutter web

**Project Type**: Flutter mobile + web (single codebase)

**Performance Goals**:
- Cold launch → login placeholder in ≤ 3 s on mid-range device
- Theme/locale switch within one rendered frame (≤ 16 ms visible latency)

**Constraints**:
- Zero new runtime packages
- All design tokens from `core/theme/` — zero hardcoded values in widget code
- All strings via ARB — zero hardcoded string literals in widget code

**Scale/Scope**: 2 new screens · 2 new Riverpod providers · 1 new theme variant · 2 ARB files · native splash on Android + iOS

| Principle | Status | Notes |
|-----------|--------|-------|

**Implementation order**: Providers → Light theme → ARB + l10n → Router → Screens → Native splash → Icon assets.

## Implementation Phases

### Phase A — Providers + Light Theme + l10n (Domain-equivalent layer)

1. `lib/core/providers/theme_provider.dart` — `ThemeModeNotifier extends Notifier<ThemeMode>`
2. `lib/core/providers/locale_provider.dart` — `LocaleNotifier extends Notifier<Locale>`
3. `lib/core/theme/app_theme.dart` — add `AppTheme.light()`
4. `assets/l10n/app_en.arb` — English translations (all keys)
5. `assets/l10n/app_ar.arb` — add splash + login keys
6. Run `flutter gen-l10n` to regenerate `lib/core/l10n/`
7. `lib/app.dart` — wire `themeProvider` and `localeProvider` into `MaterialApp.router`
8. Write unit tests for both notifiers

### Phase B — Routing

9. `lib/core/router/app_routes.dart` — add `splash`, `login` constants
10. `lib/core/router/app_router.dart` — `initialLocation: AppRoutes.splash` + 2 new routes
11. Run `dart run build_runner build` to regenerate `app_router.g.dart`

### Phase C — Screens

13. `lib/features/auth/presentation/screens/login_placeholder_screen.dart`
